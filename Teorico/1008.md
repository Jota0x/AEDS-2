# Regras gerais para notação 

- indicam a tendencia de cresciemnto de uam funcao;
- ignoram as contantes e os termos com menor crescimento das funcoes de complexidade.
  
## Diferença entre as Notações

- O é o limite superior
- $\Omega$ é o limite inferior, logo, se um algoritimo é $\Omega$(f(n)), ele também será $\Omega$(g(n)) para toda função g(n) tal que "g(n) é menor que f(n)"
-  $\theta$ é o limite justo, logo, g(n) é O(f(n)) and $\Omega$(f(n)) se e somente se g(n) é $\theta$f(n)

## Definição da Notação O

- g(n) é O(f(n)), se existirem as constantes positivas c e m tais que, para n >= m, temos que |g(n) <= c * |f(n)|
